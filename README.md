# Project Ascenso

> An enterprise-grade psychological resilience platform and cognitive gym designed to train and strengthen the human nervous system through simulated stressors, real-time AI voice interventions, and longitudinal analytics.

---

## 🧠 Overview

**Project Ascenso** is an advanced platform built to help users construct emotional and psychological resilience. By safely simulating controlled stressors across multiple environmental and social domains, the system monitors physiological/behavioral responses and delivers dynamic, real-time AI interventions when stress thresholds are breached.

---

## 🌟 Key Features

*   **Four-Domain Stress Simulation:**
    *   *Primal:* Environmental and sensory pressure simulations.
    *   *Social:* Interpersonal conflict and social friction scenarios.
    *   *Crisis:* High-stakes, rapid decision-making environments.
    *   *Existential:* Complex philosophical and ambiguous scenario evaluations.
*   **Real-Time AI Voice Interventions:** Dynamic adaptive feedback triggered when user stress or cognitive load thresholds are exceeded.
*   **Longitudinal Analytics:** Comprehensive tracking portals for monitoring resilience growth, recovery rates, and stress patterns over time.
*   **Secure Cloud Backend:** Powered by Supabase for robust user authentication, real-time data sync, and structured relational data storage.

---

## 🛠️ Tech Stack & Architecture

*   **Backend & Database:** Supabase (PostgreSQL, Auth, Edge Functions)
*   **Core Logic / AI Processing:** Python, Machine Learning pipelines, and AI speech/response models
*   **Architecture:** Modular client-server architecture featuring automated graph-based documentation management
